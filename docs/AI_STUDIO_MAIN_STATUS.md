# Estado de main para Google AI Studio

La rama `main` está configurada en modo Kotlin/Compose, sin NDK, Firebase, Gemini API, secretos ni firma manual.

La compilación automática valida:

- pruebas unitarias disponibles;
- ensamblado del APK debug;
- Android SDK 36;
- Java 17;
- Gradle 9.3.1.

Importar en AI Studio seleccionando la rama `main` y conservando `freecad.native.enabled=false`.
